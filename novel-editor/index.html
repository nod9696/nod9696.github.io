OAuth クライアント ID の取得方法
  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」→「有効なAPI」から Google Drive API を有効化
  3. 「認証情報」→「OAuth クライアント ID を作成」→ 種類は「ウェブ アプリケーション」
  4. 「承認済みの JavaScript 生成元」にこのアプリの URL（例: https://nod9696.github.io）を追加
  5. 発行されたクライアント ID を上の欄に貼り付けて保存

Notion 同期

Notion APIはブラウザから直接呼べないため、中継役として小さなGoogle Apps Scriptを 自分のアカウントにデプロイして使います。作品データは指定した親ページの下に、 プロジェクトごとの子ページとして保存されます。

未設定

Notion連携の設定方法
  1. notion.so/my-integrations で「New integration」→ Internal を選び作成
  2. 発行された「Internal Integration Secret」をコピーして上の欄に貼り付け
  3. Notion側でバックアップ用の新規ページを作成（例：Suzuri Novel Backups）
  4. そのページの右上「…」→「コネクト」→ 作成したインテグレーションを追加して共有
  5. ページを開いた状態でURLからページIDをコピーし、上の欄に貼り付け
  6. 下の「GASプロキシの作り方」の手順でスクリプトをデプロイし、URLを貼り付けて保存
GASプロキシの作り方
  1. script.google.com で新規プロジェクトを作成
  2. 配布した notion-proxy.gs の中身を丸ごと貼り付け
  3. 「デプロイ」→「新しいデプロイ」→種類は「ウェブアプリ」
  4. 実行ユーザー：自分／アクセスできるユーザー：全員 に設定してデプロイ
  5. 発行された /exec で終わるURLを上の「GASプロキシURL」欄に貼り付け
